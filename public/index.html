Quick start — agent usage

# 1. GET the 402 payment challenge
curl -X POST https://extractpdf.xyz/api/extract \
  -H "Content-Type: application/json" \
  -d '{"url":"https://example.com/report.pdf"}'

# Returns HTTP 402 with payment requirements
# 2. Sign the USDC authorization with your wallet
# 3. Retry with X-PAYMENT header
curl -X POST https://extractpdf.xyz/api/extract \
  -H "Content-Type: application/json" \
  -H "X-PAYMENT: <signed-authorization>" \
  -d '{"url":"https://example.com/report.pdf"}'
